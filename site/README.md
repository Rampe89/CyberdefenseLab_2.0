# CyberDefense Lab – Website-Dateien

Dieser Ordner enthält die statische Website. Start, Veröffentlichung, Reparaturen und Prüfhinweise stehen in der README eine Ebene darüber.

Die Labs sind Simulationen. Lokale Passwörter und Flags dienen der Unterrichtssteuerung und sind kein echter Zugriffsschutz. Für das Cookie-Lab einen lokalen Webserver oder die veröffentlichte Website verwenden.
